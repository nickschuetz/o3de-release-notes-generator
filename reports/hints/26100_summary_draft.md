O3DE 26.10.0 rebuilds the foundation under the Editor and brings robotics simulation closer to the tooling its community uses every day. The Editor and all of its tools now run on a standard **Qt 6.10.2**, replacing the custom Qt 5.15.2 build the engine had carried since its first release. Several months of follow-up work rides along with it: a reworked Entity Inspector with consistent keyboard shortcuts across the Inspector and the LyShine UI editor, undo in the Asset Editor, a component menu for UI canvases, and fixes for the crashes, docking and styling regressions that an upgrade of this size turns up. Apple Silicon joins the platform list in experimental form with native **Mac ARM64** builds, and support for building on macOS with non-Apple Clang. Linux gains initial **Wayland** support for the game launcher, with the Editor able to force the XCB platform plugin where needed. Configuration files for **Emscripten** lay the groundwork for a WebAssembly target.

Robotics is where this release goes deepest. The **ROS 2 Robot Importer** has been restructured around an import session that tracks referenced assets and reports build status, with its parsing code collected into one place and its URDF-era naming corrected now that it parses SDF. The **ROS 2 camera** can publish compressed images, with runtime fallbacks for depth formats. **SimulationInterfaces** supports the 2.1.0 package that ships with ROS 2 Lyrical Luth alongside 1.4 through 1.6, adds the SpawnEntities service and spawn notifications, handles `INVALID_POSE`, and removes simulated entities explicitly before a level unloads. **libsdformat** moves to 16.0.1. On the physics side, **ArticulationLink** computes inertia tensors automatically, closing a long-standing mismatch between O3DE and Isaac Sim in joint chains, PhysX gains an enhanced-determinism option, and the removal of PhysX 4 is complete. **DetourCrowd** joins the Recast Navigation integration, giving agents collision avoidance and smooth steering.

Rendering picks up **Ground Truth Ambient Occlusion** as an alternative to SSAO, following the [SIG-Graphics-Audio RFC](https://github.com/o3de/sig-graphics-audio/blob/main/rfcs/GTAOIntegration/Proposed%20RFC%20Feature%20GTAO%20%28Ground-Truth%20based%20Ambient%20Occlusion%29.md). The **Unlit** material family grows cutout and blended opacity, double-sided rendering, optional shadow casting and billboards, and moves opaque Unlit onto its own shader path. Decals render correctly on metallic surfaces, the decal texture array cap rises from 5 to 16, and decals gain a maximum draw distance. Mesh particles get StructuredBuffer-based per-instance rendering, fixing GPU crashes on the low-end pipeline. The **AZSL shader compiler** now lives in the engine source tree and builds as a host tool, so every platform compiles the same compiler. The Metal, Vulkan and DX12 backends each receive correctness fixes, including a use-after-free in Metal command buffer completion.

Under the hood, the engine keeps trading custom code for the standard library: `AZStd::move`, `array`, `span` and `pair` now alias their `std` counterparts, SFINAE gives way to C++20 concepts across AZStd, the allocators are refactored and dlmalloc and nedmalloc are gone, and `AZ::Transform` shrinks from 48 to 32 bytes with SIMD-packed translation and scale. The Sandbox `IPlugin` system inherited from CryEngine is removed in favour of Gems, and the first pass of legacy Cry cleanup lands. The **Class Wizard** can target any project or Gem and build target, templates can inherit from one another, and a new **GameplayGem** template scaffolds component controllers. Builds move to CMake 4.2.3, Android NDK r27d with Clang 18, and FetchContent-based third-party dependencies that cache across configurations and patch with patch-ng. Automated review now covers iOS and Mac, runs Android on Linux, and a nightly canary tests upcoming compilers before they break anyone. Networking fixes a crash on failed DTLS handshakes, trims one to two seconds off every encrypted connect, and closes an out-of-memory denial of service from malformed client input.
